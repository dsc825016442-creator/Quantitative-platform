# 市场与组合研究平台：数据源与补数方案

更新日期：2026-08-15

## 1. 当前 Tushare 能力（已由本地账户实测）

| 能力域 | 当前可用数据 | 可支撑页面 | 状态 |
|---|---|---|---|
| A 股与指数行情 | `daily`、`daily_basic`、`index_daily`、复权因子 | 结论、温度计、登指数、判断标尺 | 可用，日频 |
| 行业与成分 | `index_classify`、`index_member_all`（含 `in_date/out_date`） | 申万一级行业、时点化行业轮动 | 可用，可避免当前成分回填历史 |
| 盈利与公告事件 | `forecast`、`express`、`disclosure_date`、财务三表 | AI 观察、新闻/事件、证据链 | 可用，公告原文仍需补 |
| 卖方预期 | `report_rc` | 盈利预期修正、行业景气扩散 | 已实测可用；历史大规模回填受权限/频次约束 |
| 资金与交易行为 | `moneyflow` / `moneyflow_ths`、龙虎榜、融资融券、大宗交易 | 大额方向、拥挤度、异常成交 | 部分接口需更高积分；“资金流”是供应商口径，不等同账户资金迁移 |
| 基金与 ETF | 基金行情、净值、份额、持仓披露 | FOF 周报、ETF 申赎与轮动 | 可用，但持仓有披露滞后 |
| 期货与利率 | `fut_basic`、`fut_daily`、`shibor` | 大类资产、指数×基差、期限结构 | 期货与 Shibor 可用；`yc_cb` 已实测无权限 |

本地实测依据：`results/tushare_alpha_capability_20260716.json` 与《新 Alpha 数据能力评估》。Tushare 官方将数据分为积分接口和独立权限接口；当前价格/权限应以官方页面为准：<https://tushare.pro/document/1?doc_id=290>。

## 2. 页面能力与数据依赖

| 平台模块 | 最小可用数据 | 生产级补数 | 关键数据问题 |
|---|---|---|---|
| 市场结论 / 温度计 | 日线、成交额、涨跌家数、估值 | 盘中 Level-1、指数实时、涨停状态 | 日频不能冒充盘中；停牌与涨跌停口径需统一 |
| “老/中/小登”风格篮子 | 自定义成分、复权行情、申万行业 | 历史股本、自由流通市值、成分变更审计 | 成分需版本化；避免幸存者偏差和未来函数 |
| 纯因子轮动 | 行情、财务、行业分类 | 点时财务、风险模型、交易成本/冲击模型 | 不能把自建风格因子称为 Barra CNE6 |
| 大额方向 | 供应商资金流、成交额 | Level-2 逐笔/委托、机构席位 | “主力净流入”是算法估计，不是真实账户流向 |
| 新闻 / AI 观察 | 公告标题、结构化事件 | 公告原文、授权新闻、研报正文、舆情 | 必须记录原文 URL、发布时间、抓取时间与版本 |
| FOF 周报 | 基金净值、季报持仓、份额 | 基金分类、穿透持仓、机构持有、实时估值 | 季报持仓滞后；实时估值只能标注为估算 |
| 指数×基差 | 指数/期货日线、合约信息 | 期货分钟、现货实时、到期与换月规则 | 主力连续序列需自建且保留可交易合约映射 |
| 证据链 | 每个指标的数据血缘与计算版本 | 原始快照、质量规则、任务日志、可重放计算 | 需要同时保存 `event_time` 与 `available_time` |

## 4. 建议付费的数据

### 4.1 先补 Tushare 自身权限（投入最小）

1. **升到 10,000 或 15,000 积分**：重点解决盈利预测、特色数据与回填频次；按官方当前个人价约 1,000 / 1,500 元年，机构价为个人价的 10 倍。
2. **历史分钟（2,000 元/年）**：用于盘中路径、滑点和事件窗口回测。
3. **实时分钟（1,000 元/月）**：用于盘中温度计、基差和告警；如果只在 QMT 内部使用，可先不买。
4. **公告信息（1,000 元/年）**：若巨潮抓取稳定性或授权成为问题，优先购买。
5. **券商研报库（500 元/年）**：用于研报正文/元数据；仍需确认文本使用与展示许可。
6. **国债收益率曲线等独立权限**：当前 `yc_cb` 已实测被拒；需向 Tushare确认单项开通条件。

价格来源：Tushare 官方权限表，页面会调整，采购前复核：<https://tushare.pro/document/1?doc_id=290>。

## 5. 推荐采购顺序

1. **现在（P0）**：保留 Tushare 为日频主库；用 AKShare + QMT 做盘中快照；接入交易所/巨潮公告原文；建立双时间戳和原始快照。
2. **第一笔小额预算**：Tushare 10,000/15,000 积分 + 公告权限。若盘中必须跨设备运行，再买实时分钟。
3. **策略进入真实资金前**：补历史分钟、交易成本、涨跌停/停牌/除权质量规则，并做多源对账。
4. **平台进入机构化或对外服务前**：从 Wind / iFinD / Choice 中选择一家主数据商，重点采购点时一致预期、基金穿透、债券曲线、风险模型与商用 API 授权。
5. **确需“Barra CNE6”品牌口径时**：单独采购模型许可；否则页面统一改名为“自建 CNE 风格代理”。

## 6. 数据治理底线

- 所有信号保存 `trade_date`、`event_time`、`available_time`、`ingested_at` 四类时间。
- 行业/指数/基金成分必须版本化，回测只使用当时可见成分。
- 财务数据按公告可见时间入库，不能用最新修订值回填历史决策。
- 每项资金流指标必须显示供应商、计算口径和“算法估算”提示。
- 原始层只追加不覆盖；清洗层保存规则版本；指标层保存代码版本与参数哈希。
- Web 页面只读取服务端聚合结果，Tushare token、终端凭据不得进入浏览器。
